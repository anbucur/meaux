# Meaux Instagram archive

Source: https://www.instagram.com/meauxsvision/

This archive contains one profile-grid image for each of the 61 posts visible during collection, ordered newest to oldest. For carousel posts, the downloaded image is the first frame / cover only. Captions are the text exposed by Instagram's profile grid; post dates, engagement counts, and additional carousel frames were not collected.

## Files

- images/ — 61 JPEGs, named by Instagram shortcode.
- posts.json — Full structured metadata and captions.
- posts.csv — Spreadsheet-friendly version of the same post metadata.
- posts.jsonl — Line-oriented copy of the post records.

The image files are copies of Instagram-rendered media. Use the original post links in the metadata for attribution and context.
